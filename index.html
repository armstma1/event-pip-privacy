Event PiP Privacy Policy

Effective date: 14 October 2026

Event PiP connects only to the Home Assistant and, in the direct-install edition, optional Frigate servers that the user configures. The developer does not operate an Event PiP cloud service and does not receive users' account details, camera images, alert rules, device identifiers, diagnostics, or usage data.

Data handled on the device

  • Home Assistant address and access token. The token is encrypted using a key held by Android Keystore and remains on the user's device.
  • Alert rules and preferences. These are stored in the app's private device storage.
  • Camera snapshots and video streams. These are transferred directly between the device and the server configured by the user for immediate display. Event PiP does not retain them after display.
  • Optional Frigate connection. The direct-install edition can connect directly to a Frigate server selected by the user.

Event PiP contains no advertising or analytics SDKs. The developer does not sell or share personal data.

Data security

The Google Play edition requires HTTPS for Home Assistant connections. The direct-install edition permits local HTTP and RTSP for compatibility with private smart-home networks; users should enable those connections only on a trusted network or through a secure VPN.

No security measure is infallible. Users control the servers and network to which Event PiP connects and should revoke the Home Assistant token promptly if a device is lost or compromised.

Android permissions

  • Internet and network-state access connect to user-configured servers.
  • Boot and foreground-service access keep monitoring active after restart when the user enables Monitoring.
  • Notification access displays service status and camera alerts.
  • Both editions can optionally use Android's display-over-other-apps permission solely to draw a bounded, non-interactive camera or message popup. The user must explicitly grant this access and can revoke it at any time. Event PiP does not inspect or capture screen content.
  • Only the direct-install edition offers an optional Accessibility fallback for TVs that hide the standard overlay setting. It does not inspect screen content, observe typed text, read controls, or collect accessibility data. Accessibility access is not included in the Google Play edition.

Retention and deletion

Configuration remains on the device until the user changes it, clears the app's storage, or uninstalls the app. Camera media is not retained by Event PiP. Users can stop processing by turning Monitoring off and can remove credentials by clearing the Home Assistant address and token and saving.

Children

Event PiP is a general smart-home utility and is not directed to children.

Changes and contact

Material changes will be published with a revised effective date. For privacy questions or deletion assistance, contact the developer through the developer's GitHub profile.
