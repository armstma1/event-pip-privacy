Event PiP setup guide

Show Home Assistant messages and camera alerts on the corner of your Google TV.

Quick start Home Assistant Frigate Troubleshooting

Quick start

  1. Install Event PiP on the TV.
  2. Enter Home Assistant, Frigate, or both. The Play edition requires HTTPS.
  3. Press Save and connect, then enable Monitoring.
  4. Enable notifications. Optionally grant display-over-other-apps permission for automatic corner popups.
  5. Add a rule: choose the trigger, then choose the camera or Frigate stream.

The Google TV phone remote makes long tokens easier to enter. Use Save to Downloads and Restore latest backup to move settings between TVs.

Home Assistant

Connect

  1. Home Assistant profile → Security → Long-lived access tokens → Create token.
  2. Copy the token into Event PiP and save.

Test a text popup

In Developer Tools → Events, enter event_pip_show in Event type:

title: Test alert
message: This came from Home Assistant
duration: 30

Automation equivalent:

actions:
  - event: event_pip_show
    event_data:
      title: "Water leak"
      message: "Leak detected under the kitchen sink"
      duration: 30
      severity: critical

Target one TV

Give each TV a unique This TV name, such as living_room_tv, then add target: living_room_tv. Omit target to broadcast to every connected TV.

Frigate without Home Assistant

  1. Use an authenticated Frigate HTTPS address, normally port 8971.
  2. Enter the address and optional username/password.
  3. Save, enable Monitoring, and add a rule.
  4. Choose Frigate as the trigger and select a camera.
  5. Choose the Frigate stream under Show this camera.

Rules can filter by camera, object, zone, and alert/detection severity. Historical reviews are ignored when monitoring starts.

Troubleshooting

  • No popup: enable Monitoring, notifications, or popup permission.
  • Listener inactive: check the URL/token and save again.
  • Snapshot but no live video: the camera integration must expose a compatible stream.
  • No Frigate cameras: use the HTTPS API address and correct port.
  • Multiple TVs: use a unique TV name and matching target.

Privacy and backups

Event PiP connects directly to the servers you configure and has no Event PiP cloud account, advertising SDK, or analytics service. Backups contain connection credentials and alert rules; keep them private.
